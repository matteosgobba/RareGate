# RareGate v2 — Dark-theme README variant

Asset: `raregate-logo-v2-dark.png` (2172 × 724, opaque RGB PNG).
Source: the unchanged `raregate-logo-v2.png`.

The README selects this version for dark color schemes and the original for
light color schemes. It retains the v2 ring, trajectories, wordmark and turquoise
accent, with light lettering on a dark background. The background was requested
to match GitHub's default dark palette; other dark palettes may differ slightly.
Prompt colors are design targets, not a pixel-level color certification.

Created with the built-in `imagegen` tool on 2026-10-17, using the original PNG
as the edit reference. Two transparent attempts had visible edge/cutout artifacts
and were rejected. The opaque version was inspected at full size and in local
README previews; the source logo was not overwritten.
